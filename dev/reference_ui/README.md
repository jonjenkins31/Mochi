# dev/reference_ui/

Generated UI mockups — design reference for whoever builds the
interface. Not documentation, not assets the app loads: nobody ships
these, and `interfaces/` never reads them.

Here rather than in `docs/` because of the audience split: `docs/` is
for someone USING Mochi or authoring a character, `dev/` is for
someone CHANGING it. A user has no reason to look at a mockup.

## What they are

Gemini-generated concepts for the player window and Studio surfaces.
Concepts, not specs — where a mockup and the shipped UI disagree, the
mockup is the older idea.

~46 MB of PNGs, committed once and not expected to change.

# Mochi is a WORKSPACE, not a library — it is never installed into
# anyone's site-packages, and nothing imports it. You run it from this
# directory with `python3 main.py`, the way a ROS workspace is run.
# That is why core/ and interfaces/ can have generic names.
#
# THE JAEGER PACKAGES ARE DELIBERATELY NOT LISTED HERE. `jaeger-os` and
# `jaeger-animation` are not on PyPI, so the only way to name them in a
# requirements file is by git URL — and a URL requirement ALWAYS forces
# a reinstall, even when a newer satisfying copy is already present.
# That silently undid the editable sibling installs setup.sh had just
# made, one line earlier, and reinstalled whatever @master happened to
# be. setup.sh installs them instead: sibling checkout first, git URL
# only as a fallback. See install_jaeger() there.

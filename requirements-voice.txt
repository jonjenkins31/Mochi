# Mochi's voice — install only if you want one.
#
#   ./setup.sh --voice
#   pip install -r requirements-voice.txt
#
# SEPARATE FROM requirements.txt on purpose. Kokoro pulls torch,
# transformers and spacy: roughly 2 GB and several minutes. A character
# player should not make everyone pay that to see a face, and v5.0
# shipped without it deliberately.
#
# Sibling checkouts are what a dev clone wants instead:
#   pip install -e ../JaegerKokoroTTS -e ../JaegerWhisperSTT
#
# Neither pins jaeger-os by URL — a URL dependency would reinstall the
# framework and could downgrade the one this app is running on.

jaeger-kokoro-tts @ git+https://github.com/JenkinsRobotics/JaegerKokoroTTS@master
jaeger-whisper-stt @ git+https://github.com/JenkinsRobotics/JaegerWhisperSTT@master
